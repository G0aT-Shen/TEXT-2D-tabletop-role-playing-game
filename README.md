# 绝夜之旅 — Journey of the Final Night

[![Python](https://img.shields.io/badge/python-3.13+-blue.svg)](https://www.python.org/)
[![pygame-ce](https://img.shields.io/badge/pygame--ce-2.5.0+-green.svg)](https://pyga.me/)
[![License](https://img.shields.io/badge/license-MIT-orange.svg)](LICENSE)

一个基于 Pygame 的暗黑 TRPG（桌上角色扮演游戏），支持单人/双人冒险。

## 游戏简介

玩家误入被黑暗吞噬的"绝夜之境"，扮演不同职业的角色，乘坐幽灵列车穿越四大章节。通过掷骰子（D20/D100）判定事件成败，每个选择都可能导向大成功或大失败。

## 特性

### 核心玩法
- 🎲 **D20/D100 骰子系统** — 技能检定、对抗检定、幸运检定，含大成功/大失败判定
- ⚔️ **回合制战斗** — 统一伤害公式，攻击/技能/防御/道具/逃跑五种行动，11种敌人+4个Boss
- 🌿 **分支叙事** — 每章1-2个关键抉择点，影响后续事件走向和阵营声望
- 👥 **双人冒险** — 两人同屏协作，分摊伤害，独立角色养成

### 成长系统
- 📜 **技能树** — 每职业9个技能节点（4基础+4进阶分支+1终极），消耗技能点解锁，二选一分支不可回头
- ⬆️ **自由属性分配** — 升级获得3点自由属性+1点职业自动加点，每4级额外1点，支持6属性自定义分配
- 🛡️ **装备系统** — 武器/护甲/饰品4槽位，4级稀有度（普通/精良/稀有/传说），16种词缀（嗜血/暗影亲和/圣光裁决/吸血等），职业专属装备
- 🎒 **道具系统** — 13种道具（圣水/急救包/附魔匕首/黎明之刃等），背包容量10格，战斗中使用
- 🏛️ **阵营声望** — 三大阵营（暗影之民/晨曦余烬/观测者），声望达到崇敬解锁被动（每回合MP回复/免死/显示DC）

### 经济与资源
- 💰 **金币 GP** — 战斗掉落、事件奖励，用于商店购买装备和消耗品
- 💎 **暗影精华** — Boss击杀、大成功事件获取，用于暗影精华商店购买技能点/属性点/传说装备
- ✨ **晨曦碎片** — 章节通关奖励，用于最终抉择和传说锻造

### 周目与难度
- 🔥 **New Game+** — 通关后继承装备和金币，重置等级从头挑战，难度递增
- ⚙️ **难度选择** — 简单/标准/硬核三档，影响敌人HP/攻击/防御倍率和掉落倍率

### 视听表现
- 🎨 **程序化场景渲染** — 6种暗黑场景（列车、森林、城堡、裂隙、神殿、废墟），7种敌人剪影，4类粒子特效（余烬/孢子/虚尘/雪花），零外部资源纯 pygame 绘制
- ✨ **战斗视觉特效** — 粒子爆发、浮动伤害数字、屏幕震动、治疗特效、Boss 脉冲光环
- ⭐ **星空背景+动态标题** — 闪烁星空、月环装饰、菜单发光效果

### 工程
- 💾 **存档系统** — 3个 JSON 存档槽位，完整序列化（角色属性/装备/技能解锁/阵营声望/章节进度），自动存档
- 📦 **单文件打包** — PyInstaller 支持，可通过 `build_exe.py` 编译为独立 exe
- 🖥️ **跨平台字体** — 自动检测 Windows/macOS/Linux 中文字体
- 🧙 **神秘商人** — 章节过渡时开放，出售装备/消耗品/暗影精华商品
- ✅ **自动化测试** — 覆盖装备、检定奖励、存档、章节数据和商店库存等核心逻辑

## 章节

1. **暗夜降临** — 列车脱轨，初遇妖魔，击败暗影巨龙（Lv.3 Boss）
2. **幽影迷途** — 深入影月森林，对抗腐化树灵（Lv.4 Boss）
3. **深渊觉醒** — 面对深渊军团，挑战深渊领主（Lv.5 Boss）
4. **绝夜终章** — 登顶绝夜神殿，与绝夜之神·诺克斯最终决战（Lv.7 最终Boss），结局分支选择

## 安装运行

```bash
pip install -r requirements.txt
python main.py
```

或直接双击 `run.bat`。

### 打包为 exe

```bash
python build_exe.py
```

输出在 `dist/绝夜之旅.exe`。常用选项：

```bash
python build_exe.py --console       # 保留控制台窗口，便于排查启动错误
python build_exe.py --no-clean      # 复用 PyInstaller 构建缓存
python build_exe.py --name MyGame   # 自定义输出文件名
```

### 运行测试

项目使用 Python 标准库 `unittest`，无需额外测试框架：

```bash
python -m unittest discover -s tests -v
```

测试覆盖装备属性与槽位、检定结果奖励、存档往返、剧情 DC 一致性、战斗引用和商店库存隔离。

## 伤害公式

```
物理伤害 = (6 + 属性修正 + 装备攻击) × 技能倍率 × 暴击系数
魔法伤害 = (6 + INT修正 + 装备攻击) × 技能倍率 × 暴击系数
实际伤害 = max(1, 总伤害 - 敌人防御/2)
```

- **命中判定**: D20 + 属性修正 ≥ 敌人防御值
- **暴击**: 自然出目 20 或刺客潜行状态，伤害 ×2
- **大失败**: 自然出目 1，自动失误
- **破甲**: 装备词缀可提供破甲值，减少有效防御
